## Want to contribute to this awesome list?

Before you submit a contribution via a pull request, please read the following guidelines first.

1) Is the relevant for academics or scholars? Please refrain from adding general tools that are great for everybody, but focus on academia.
2) Is the tool you are suggesting in fact really awesome, tried and tested and therefore worthy to be included in this list? Please let me know if you're a researcher yourself and have tried it out or if you have testimonials from researchers who are happily using the tool.
3) Is the tool free so that people who don't have the financial resources may also use it? There has to be a fully free tier and not just a free try-out or teaser and I will decide on a case-by-case basis regarding hybrid tools. This is not a list advertising paid products.
4) Does the tool or a very similar tool already exist in the list? For the latter, you can argue why yours is superior and I will decide inclusion on a case-by-case basis.
5) Please submit a separate pull request for each suggestion.
6) Think about what category your suggestion belongs into or suggest a new one, if it doesn't exist.
7) Name your suggestion with a useful title.
8) Each entry should roughly follow the same format: ```[TITLE OF RESOURCE](Link to resource): Short description of what the resource is and does.```
9) Check your spelling before submitting the pull request!
10) Read the guide [here](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request) on how to do a pull request.
